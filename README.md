# Cropper

Десктопное приложение для подготовки фото к Instagram-каруселям: бесшовные сплиты, коллажи из полос 21:9, вертикальные полосы со словом, постеры. Работает и с телефона через домашний Wi-Fi.

## Установка
`dist/Cropper Setup 1.0.0.exe` → установить → ярлык «Cropper» на рабочем столе.
При первом запуске Windows спросит доступ к сети — разреши «Частные сети» (нужно для телефона).

## Каталог (память между запусками)
Как в Lightroom: импортированные фото и все карусели сохраняются автоматически в каталог — по умолчанию `Изображения/Cropper/Каталог` (`catalog.json` + папка `Фото`). Закрыл приложение — при следующем запуске всё на месте.
- ⚙ → «Сменить каталог…» — выбрать другую папку (например, на большом диске).
- Импорт: «Копировать в каталог» (по умолчанию, надёжно) или «Только ссылка на файл» (экономит место).
- «✕» на фото убирает его из каталога; копия уходит в корзину Windows, исходники не трогаются.
- Несколько каруселей: список внизу, «+ Новая», ✎ — переименовать.
- При каждом запуске предыдущая версия сохраняется в `catalog.bak.json`.

## Шаблоны
| Шаблон | Что делает |
|---|---|
| Кино-карусель | Обложка из 3 полос ≈21:9 (2.4:1) + каждая полоса разворачивается в 3 бесшовных слайда. Кадр обложки и разворота связан. |
| Кино-триптих | Только обложка из 3 горизонтальных полос |
| Триптих с линиями | То же с тонкими разделителями (стиль nanuqdogphotography) |
| Полосы + слово | 2–8 вертикальных полос из разных фото, по букве на полосу (стиль davvanc) |
| Сплит на 2 / Панорама на 3 | Один кадр режется на N слайдов встык |
| Одиночный | Кроп под формат |
| Постер | Кадр + заголовок с разрядкой |

Математика: 3 слайда 4:5 рядом = 2.4:1 — ровно одна полоса обложки, поэтому обложка и развороты совпадают пиксель в пиксель.

## Управление
- Клик по фото в библиотеке — выбрать (номер = порядок), затем шаблон сверху.
- Перетащить фото в ячейку / двойной клик по ячейке — заменить фото.
- Мышь/палец — двигать кадр, колесо/щипок — зум, стрелки — точный сдвиг, `+`/`−` — зум.
- `Ctrl+E` — экспорт. Файлы: `carousel_01.jpg…` в выбранной папке (по умолчанию `Изображения/Cropper/Экспорт`).

## Телефон
Кнопка «Телефон» → QR-код. Телефон в той же Wi-Fi сети, ПК включён и Cropper запущен.
На телефоне: обработать и сохранить в «Фото» (долгое нажатие на картинку) или «Отправить на ПК» — фото появятся во «Входящих» в приложении на компьютере.

## Онлайн-версия (вне дома)
**https://kakasobaka9.github.io/cropper/** — открыть на телефоне, «Поделиться» → «На экран Домой».
После первого открытия работает без интернета. Фото обрабатываются на самом телефоне и никуда не загружаются.
Кнопка «Сохранить / поделиться» в окне экспорта отдаёт слайды в «Фото» или сразу в Instagram.
Обновляется автоматически при каждом пуше в `main` (папка `app/`, GitHub Actions → Pages); новая версия подхватывается со второго запуска.

## Обновления и откат
Приложение само проверяет GitHub Releases при запуске и раз в 2 часа, качает новую версию в фоне и показывает кнопку «⬆ Версия X готова — перезапустить» (или ставит её при закрытии).
⚙ → «Обновления и версии» — список всех версий, любую можно установить поверх. При откате на старую автообновление выключается.
Если приложение не запускается совсем — установщик любой версии лежит на https://github.com/kakasobaka9/cropper/releases

### Как выпустить новую версию
1. Поднять `version` в `package.json`, закоммитить и запушить.
2. `git tag vX.Y.Z && git push origin vX.Y.Z` — GitHub не публикует релиз без существующего тега.
3. `GH_TOKEN=$(gh auth token) npm run release`
4. `gh release edit vX.Y.Z --notes "что нового"` — текст видно в списке версий в приложении.
